# w-u.top — 个人主页

一个纯前端的极简个人主页 / 实验性着陆页，暗色极光风格。

**在线访问**：[w-u.top](https://w-u.top)

## 特点

- **视觉效果**：极光背景（aurora）、轨道环、漂浮字母、噪点与网格纹理
- **交互**：自定义光标（双层跟随）、加载动画（HELLOWORLD 进度条）
- **轻量**：单文件 `index.html`，无框架、无外部依赖，离线可用

## 项目结构

| 文件 | 说明 |
|------|------|
| `index.html` | 全部页面（HTML + CSS + JS 内联） |
| `CNAME` | 自定义域名（w-u.top） |

## 本地预览

直接用浏览器打开 `index.html`（需启用 JavaScript）。

## 部署

通过 GitHub Pages 发布，绑定域名 `w-u.top`。
